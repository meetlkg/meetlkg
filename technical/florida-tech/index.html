Florida Technology Requirement

A project from my earlier engineering notebook. Original descriptions, resources and demonstrations are preserved below.

one curiosity
leads to another
https://github.com/gok03/florida-tech-req

The primary aim of the project was to jot out the jobs available in the Florida region and visualise the same to show different data point like highly required skills, domains of the company, etc.

We extracted the jobs using tools like beautiful soup from public job boards and portals.
This was stored and accessed using JSON into the python script.

We then used NLP to extract keywords and job information from the dumps to process further.

The final app showcases the various categorical job opening in the state of Florida in Map with easy navigation and data exploration.
