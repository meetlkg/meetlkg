# gok03.com

Personal website for Gokulavasan Murali. Static HTML and CSS; no build step or package installation required.

## Preview

Run `python3 -m http.server 8765 --bind 127.0.0.1` from this directory, then open http://127.0.0.1:8765.

## Structure

- `index.html`: current portfolio homepage
- `static/portfolio.css`: responsive homepage styles
- `static/mark.svg`: homepage favicon
- `archive.html`: preserved earlier homepage, with its Accenture entry marked historical
- `projects/`, `works.html`, `slm-talk/`: existing project and talk pages
- `CNAME`: existing custom domain configuration; preserved

## Content notes

The refresh uses the existing portfolio, the repository's PyConf Hyderabad 2026 talk page, and the public LinkedIn profile at https://www.linkedin.com/in/gok03/.
