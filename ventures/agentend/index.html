From an intent to a working backend.

An agent-powered product needs more than a model call. It needs a way to route intent, supply context, coordinate work and deliver results back to the interface.

The approach

Agentend explores a capability-oriented backend. A kernel routes intent, a context bus supplies memory, workers carry out tasks and events stream to the frontend. This makes agent behavior part of the application architecture.

  1. 1Route intent
  2. 2Supply context
  3. 3Execute & stream
  • Capabilities give the application a domain-focused unit of behavior.
  • Workers and orchestration structure how a task moves through the system.
  • The project documents AG-UI, MCP and A2A integrations, along with observability.

Explore & contribute

Read the architecture, explore an example and use the repository to discuss a change or submit a contribution. Check the project’s license and contribution guidance before building on it.
