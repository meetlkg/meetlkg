# Interactive portrait

The selected full bust is the approved smoothed Pixel3DMM/FlexAvatar reconstruction, retaining all 202,183 Gaussian primitives. No runtime inference or external avatar service is used. The PLY is ~13.7 MB; sparse facial fields are ~1.8 MB. Assets, renderer and texture are served locally.

`interaction.bin` contains 30,599 uint32 primitive indices, then UV/front-mask float32 triplets, then three channel-major int16 fields of seven components (XYZ, RGB, opacity). Metadata stores scales and correspondence sentinels. Built by `avatar-studio/prepare_portrait_interactions.py` in the parent workspace using the existing fitted identity/decoder fields. Facial shaders require uncompressed, unoptimized original primitive order.

Blink and jaw motion are retargeted from the fitted FLEX-1 decoder. Photometric lid colors cover baked iris texture during blinking. Cursor gaze uses bounded resampling of the source eye appearance on the existing reconstructed 3D surface. It is an appearance approximation, not a separately reconstructed eyeball rig. Hover adds a small procedural mouth-corner lift, brow lift and soft blink; clicking gives a slight camera nod. These accents do not establish anatomical accuracy.

The large centered hero turns the head toward the cursor (up to ±10° yaw / ±4° pitch) with smooth neck attachment and fixed shoulders. The shader transforms Gaussian centers and covariances using the neck deformation Jacobian, and the CPU sorter uses corresponding centers. Eye motion is coordinated with the turn. All view paths share a combined camera/head exposure bound of ±15° yaw and ±4° pitch. There is no free orbit, pan, zoom, auto-rotation, back or underside control. Canvas drag, arrows and buttons use the same bounds. Reduced-motion preferences and Pause neutralize facial animation; the portrait remains manually turnable. Off-screen/hidden canvases stop rendering. Nothing is sent to a camera, microphone or remote tracking service for cursor interaction.
